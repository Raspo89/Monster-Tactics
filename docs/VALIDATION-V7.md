This was an economy/result integration fixture, not a claim about match balance.

Round stages,37 hexgrid, parchment menus, shop prices, canonical rarity letters, physical card inspector and overhead fallback animations rendered. WebGL is unavailable in the cloud browser, so GPU rendering remains visually unverified. The offline HTML is checked for embedded registries; desktop file-open behavior is not browser-tested here.

Progress is local per browser, not server-backed or anti-cheat. A single localStorage record saves inventory, coins and match receipts together. Existing custom decks are preserved but normal new matches require ownership. Training borrows cards without unlocking them and awards no progression. Early standard AI decks for the four starter tribes use the same common/uncommon starter constructions; other enemy races use the existing native presets. All sides retain the same battle rules and resource generation.
