# Version 5 — all monster races and custom decks

105 tests passed across six targeted suites, including a complete normal-AI match for each of the 16 races with native decks, legality/resource/occupancy checks; the complete four-race regression suites; source combat/rune rules; and 13 new catalogue/racial/deck tests. Two targeted assertions were added for activated attacks against Spectres and Robot buff immunity, and a poison test was corrected to use the actual poison attacker. See final targeted run.

The catalogue adds 128 actual named AT_NONE monsters from the recovered native CSV,8 perrace, preserving cost/power/health/rarity/class/texture. All selected monsters have positive attack. There are 180 total available cards, including the 52 existing prototype/support cards. Original races are Human,Elf,Orc,Zombie,Lizard,Dwarf,Minotaur,Werewolf,Golem,Elemental,Cyclops,Skeleton,Robot,Imp,Spectre,Vampire. All 16 native racial bonuses are represented in engine mechanics and translated card inspection text. Flame upkeep is supported; original active flame-causing cards have not yet been ported.

Browser QA: selected Golem preset, inspected Kafius (name/race/class/passive), added fourthcopy, renamed and saved 31-card deck, observed it selected in prebattle picker, chose Dwarf enemy deck, started battle, inspected Tracvar from hand during mulligan and battle, then summoned it to a legal adjacent hex. Its original fallback model rendered correctly. WebGL unavailable in cloud browser, so GPU model rendering remains visually unverified. Exact card texture colours are used in portraits/3 D; raster fallback uses the archetype default texture. All 128 portraits and all referenced 67 models/134 directional sheets passed assetcoverage checks.

Saved decks migrate prior per-hero custom decks and support multiple named collections; the selected deck is used without silent substitution. The hero choice is independent of monster races. Collection filters expose all 16 races. Native starter sets contain 8 cards each; Vampire subset is artillery, Elemental subset warrior/artillery. The full 1600 monster catalogue and active abilities are not claimed implemented.

Source evidence: reference/native-rules/RACE-PASSIVES-V 5.md; asset provenance/reproducers: reference/conversion/RACE-ASSETS-V 5.md. Standalone HTML embeds assets; direct desktop file-opening is statically verified, not browser-tested here.
