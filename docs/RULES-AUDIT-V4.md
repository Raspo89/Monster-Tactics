# مراجعة قواعد Combat Monsters — الإصدار الرابع

المصادر: نصوص المساعدة والتعليم من XAPK5.6، الفيديو المرفوع، و14 جدولًا أصليًا استُعيدت من مكتبة APK. كما جرى فحص مسار الهجوم والحركة والسحب في الشيفرة الأصلية دون تشغيلها. الأدلة والجداول والقدرات والثوابت وعناوين الاستخراج محفوظة في reference/native-rules.

| القاعدة | نتيجة المراجعة والتطبيق |
|---|---|
| الاستدعاء من اليد | خانة فارغة ملاصقة للقائد الحالي، للطرفين. يوجد تحقق إضافي حتى في مسار تقييم AI. |
| الإحياء البعيد السابق | قدرتا Z06/Z08 التجريبيتان لا تعملان في قواعد الأصل؛ لم تُثبتا كقدرات لهذه البطاقات. |
| الهجوم الأساسي | مجاني: AT_ATTACK/AT_SHOOT/AT_BLAST/AT_LOB تكلف 0 موجو. |
| الرد التلقائي | أُلغي في قواعد الأصل؛ مسار الهجوم الأساسي لا ينفذ ضربة مضادة عامة. |
| ترتيب الحركة والهجوم | يمكن استخدام الحركة المتبقية بعد الهجوم. المحارب غير القائد يستطيع حركتين عند ترك الهجوم. المدفعية تختار الحركة أو الهجوم. |
| مدى الفئات | محارب1، ساحر1–2، رامٍ2–3، مدفعية3 فقط. الرمح التجريبي لا يغيّر المدى الأصلي. |
| الإرهاق | الجديد يهاجم ولا يمشي، إلا عند وجود Rune of Much Monster Blitzing. |
| الدفاع | يمتص الضرر أولًا ويُستهلك ثم يتجدد في دور مالكه. الدرع والترس منفصلان ويمكن جمعهما. |
| السلاح | يطابق فئة الوحش/القائد. السلاحان الحاليان للمحاربين. لم تُضف كل أسلحة الأصل بعد. |
| الصحة | الزيادة والعلاج غير مقيدين بالصحة المطبوعة؛ قد ترتفع الصحة عنها. Regen=2 كما في الثوابت، ويزيل الحالات السيئة. |
| القائد | أربعة قادة من الجداول الأصلية بدل إحصاءات30صحة/7موجو الموحدة: Dean،Tut،Grumsnik،Raeynor. |
| اليد الأولى | ست بطاقات، ولا يسحب صاحب البداية في أول دور. |
| حد اليد | 200 في دالة السحب الأصلية؛ توجد صفحات لليد عند تجاوز8 بطاقات ظاهرة. |
| نفاد المجموعة | ضرر أرماغيدون المتزايد لجميع مخلوقات صاحب المجموعة، مرة لكل upkeep. |
| البشر | +1 قوة لكل مخلوق صديق مجاور. |
| الموتى | +1 صحة عند موت مخلوق. |
| الأورك | +1 قوة لكل أورك آخر دون حد+3 القديم. |
| الجان | +4 صحة إذا كان جميع وحوش الفريق جانًا؛ القادة لا يدخلون في مقارنة الأعراق؛ تزول الزيادة عند الاختلاط. |
| الرون | أربع قواعد في المناوشة: قاعدتان لكل طرف؛ له صحة ويمكن تدميره. صحة15 موثقة بصريًا بالفيديو، لم تُربط بثابت native في التدقيق. |
| وضع الرون | استهداف قاعدة مملوكة؛ استبدال السابق مسموح. توجد رونات خاصة بالأصل تسمح بقواعد أخرى، لم تدخل هذه المجموعة بعد. |
| هجوم الرون | أي فئة من خانة ملاصقة فقط. القدرة الهجومية الأساسية تُستهلك ولا يوجد رد من الرون. |
| تكلفة الرون المماثل | التكلفة الأصلية +2 لكل نسخة مماثلة نشطة تحت تحكمك، بما في ذلك إعادة وضع نفسه. |
| العادي | 30–200 بطاقة، أربع نسخ من أي بطاقة، ولا قيد عرقين. |
| الفريد | 50 بطاقة مختلفة بالضبط. |
| القبلي | عرق وحوش واحد، والوحوش60% على الأقل. |
| البسيط | عادي وغير شائع فقط. |
| الحشود | وحوش فقط. |

## الحدود المهمة

هذه مراجعة مطبقة للقواعد الأساسية المتاحة، وليست استعادة كاملة لكل 1600سطر وحوش أو266رونًا أو542تعويذة. جداولها استعيدت لكن معظم مجموعة الوحوش والتعاويذ الحالية ما زالت مجموعة النموذج السابق؛ بعض قدراتها غير أصلية أو مبسطة. لم أعتبر عدم العثور على نص استدعاء بعيد دليلًا على استحالة كل استثناء خاص. القيد المطبق هنا هو الاستدعاء العادي من اليد.

العرض ثلاثي الأبعاد لم يُختبر بصريًا في بيئة العمل لعدم توفر WebGL؛ العرض البديل بحركات الأصل يُختبر في المتصفح. HTML المستقل يُفحص من حيث تضمين الموارد، لكن فتحه مباشرة محليًا لا يتاح في متصفح العمل.
